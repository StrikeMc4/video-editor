# docs

Project documentation. Start here when you open the repo.

| Where | What |
|---|---|
| [`../README.md`](../README.md) | What the app is, how to run it, **where every file is** |
| [`../CLAUDE.md`](../CLAUDE.md) | Rules for agents: data model, conventions, gotchas, how to verify |
| [`../VIDEDIT.md`](../VIDEDIT.md) | User guide (keep it in sync with visible behaviour) |
| [`openspec/`](openspec/README.md) | **Specs of what the app does now** and a **log of every change made** |

## Which one do I read?

- Need to know *where code lives*: `README.md` → File structure.
- Need to know *how to write code here*: `CLAUDE.md`.
- Need to know *what the app is supposed to do* in an area (timeline, text, export, …): `openspec/specs/<area>/spec.md`.
- Need to know *why/when something was added*: `openspec/changes/archive/`.
